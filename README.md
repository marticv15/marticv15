### 👨‍💻 Sobre mi

Salutacions! Sóc en **Martí**, alumne de l'**Institut Tecnològic de Barcelona (ITB)**. Sóc una persona altament motivada i curiosa, amb moltes ganes d'aprendre tota mena de programari i tecnologies. Crec fermament en marcar-me grans objectius i assolir-los a base de prova i error, resiliència i aprenentatge continu. 🚀

- 🔭 Actualment treballant en: **Idees per desenvolupar aplicacions que resolguin problemes quotidians (des de petites tasques fins a reptes complexos) per optimitzar el dia a dia.**
- 🌱 Aprenent activament: **Assentant i ampliant les bases de Python, HTML, CSS i JavaScript.**
- 🎯 El meu objectiu principal: **Crear solucions útils, optimitzar processos i compartir els meus projectes i aprenentatges amb la comunitat.**
- 💬 Pregunta'm sobre: **La meva motivació per programar, resolució de problemes o com afronto nous reptes tecnològics.**
- ⚡ Dada curiosa: **Tinc clar que el millor codi neix de l'error, la pràctica constant i la passió per millorar cada dia.**
